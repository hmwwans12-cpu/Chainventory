# Architecture Decision Records

Keputusan arsitektur yang butuh konteks lebih dari komentar kode
(temuan audit #11: keputusan menggantung jangan hanya jadi baris TODO).

Format: satu file per keputusan (`NNNN-judul-singkat.md`) dengan
Status / Konteks / Keputusan / Konsekuensi. Status yang sudah usang
wajib diperbarui di file yang sama, bukan ditimpa diam-diam.
